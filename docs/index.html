Features

All the things people ask Task Manager for

TaskForge started from the most-requested Task Manager features, then added the tools you normally have to hunt down separately.

🎮

Detailed GPU monitoring

Every GPU's load, each engine (3D, copy, video, compute), dedicated and shared memory, temperature, clocks, fan and power, plus GPU use per app.

🌐

Per-app network speed

See exactly which program is downloading or uploading, live, like Resource Monitor but in the process list.

❤

"Why is my PC slow?"

A health check with a 0–100 score, plain-English findings and one-click fixes for hogs, full drives, leaks and heavy startup apps.

🚑

Fix Windows

59 built-in Windows repairs (SFC, DISM, network resets, Windows Update reset and more), searchable by symptom.

📅

24-hour history

CPU, memory, GPU and network for the last day, saved between sessions, with the process behind every spike.

⚡

Automation rules

Give games high priority, pin apps to cores, block annoying updaters, tame CPU hogs, and get alerts when apps misbehave.

⏸

Suspend, resume & restart

Freeze a process without killing it, or restart it with the same command line. Threads and memory dumps too.

🛡

Is this program safe?

Signature check for every program, and a one-click VirusTotal lookup by file hash. Nothing is uploaded.

🔓

What's locking this file?

Find the program that keeps a file "in use" and close it. Or point at any window to see which app owns it.

📈

Memory-leak detector

Every app is sampled once a minute; steady growth for 15+ minutes gets flagged before it slows you down.

🚀

Complete startup list

Startup apps with real High/Medium/Low impact, plus scheduled tasks and services that sneak in at sign-in.

🔔

Tray icon & mini monitor

Live CPU/GPU bars in the system tray and a tiny always-on-top monitor for gaming or rendering.

Health check

Plain answers to "why is my PC slow?"

TaskForge looks at your processor, memory, drives, GPU, memory leaks, startup apps and uptime, then tells you what's actually wrong, with a button to fix it.

  • 0–100 health score that updates live
  • One-click fixes: end a hog, lower its priority, clean up a drive
  • Startup impact measured with Windows' own thresholds
GPU

See what your graphics card is really doing

TaskForge uses the same rule as Task Manager for overall load (the busiest engine), then shows far more detail.

  • Every engine: 3D, copy, video decode/encode, compute
  • Memory: dedicated, shared, and the budget Windows allows
  • Sensors: temperature, power, clocks, fan speed, where the driver reports them
  • Per app: GPU %, engine in use and GPU memory

Install

Up and running in a minute

One small file. Installs just for you, with no admin prompt, and uninstalls from Settings like any other app.

Download

Get TaskForge-Setup.exe from the latest release.

Run it

Double-click the file. If Windows shows "Windows protected your PC", click More info → Run anyway.

Install

Click Install. Optionally add a desktop shortcut and start it when you sign in. Or just run it without installing.

⚠ TaskForge isn't code-signed yet (certificates are expensive for a free project), so Windows SmartScreen may warn you the first time. The full source code is on GitHub for anyone to check, and you can build the exe yourself.

FAQ

Questions

Does it replace the built-in Task Manager?

No. TaskForge runs alongside it and doesn't change any Windows settings to take its place. Use whichever you like, and uninstall TaskForge any time from Settings › Apps.

Is it safe? Why does Windows warn me?

The warning appears because the exe isn't signed with a paid certificate, not because anything was detected. TaskForge is open source: every line is on GitHub, and the exe can be built from it with one command. It doesn't send any data anywhere; the VirusTotal check only opens a lookup by file hash in your browser when you click it.

Do I need to run it as administrator?

No, but some things need it: per-app network speed (Windows requires admin for event tracing), managing system processes and services, and the Fix Windows repairs marked "Admin", which ask for permission when you run them. There's a "Restart as admin" button in the app.

How much CPU and memory does it use?

Very little. Sampling runs on a background thread once a second, and the window only redraws when there's new data. Version 1.2 roughly halved CPU use compared to 1.1.

Why don't I see GPU temperature or fan speed?

Those come from the graphics driver, and some GPUs (often integrated ones) don't report them. TaskForge tells you when a value isn't available.

Are the Fix Windows repairs safe to run?

They're the same built-in Windows tools a technician would use (SFC, DISM, CHKDSK, netsh, Defender and so on). Each one says what it does, and anything with side effects, like resetting network settings, asks you to confirm first. Creating a restore point first is one click away.

Where are my settings and history stored?

In %APPDATA%\TaskForge\data, on your PC only.
